# SyncVoice

Контроль качества звонков: записи скачиваются из FreePBX, распознаются
(субтитры), контролёр прослушивает звонок в плеере с субтитрами, заполняет
форму контроля и выгружает дневной отчёт «Отчет записи ДД.ММ.ГГГГ.xlsx».

## Установка на Windows

1. Установите Python 3.12 с https://www.python.org/downloads/windows/
   (отметьте «Add python.exe to PATH»).
2. Скопируйте папку SyncVoice на ноутбук и запустите `setup.bat`.
   Он поставит зависимости, подготовит базу и создаст ярлык **SyncVoice**
   на рабочем столе.
3. Запускайте SyncVoice ярлыком: откроется окно консоли (не закрывайте его —
   в нём работают сайт и фоновая обработка) и браузер с приложением.
   При первом запуске скачивается модель распознавания (~500 МБ).
4. В приложении откройте **Настройки**: адрес АТС, логин и пароль
   (пароль хранится в Диспетчере учётных данных Windows), инициалы
   контролёра, список интервьюеров «номер имя». Нажмите
   «Проверить подключение».

## Подсказки ИИ (Gemini)

Необязательно. Gemini по расшифровке предлагает «Город проживания»,
«Город слушания» и «Радиостанции / не слушал»; контролёр проверяет их
при прослушивании. В Google уходит только текст расшифровки — без аудио,
номера телефона и интервьюера.

1. Скопируйте `.env.example` в `.env` (рядом с `manage.py`) и заполните
   `GEMINI_API_KEY`, при необходимости `GEMINI_PROXY_URL`,
   `GEMINI_PROXY_USERNAME`, `GEMINI_PROXY_PASSWORD` — прокси используется
   только для запросов к Gemini.
   `GEMINI_COMPARE_MODEL` — отдельная модель для сверки анкеты с разговором
   (если пусто — та же, что `GEMINI_MODEL`).
   Порядок выбора модели: поле в «Настройках → ИИ (Gemini)» → `.env` →
   `gemini-3.1-flash-lite`; для сверки: её поле в настройках →
   `GEMINI_COMPARE_MODEL` → модель подсказок. Что используется сейчас и
   откуда — написано в настройках под полями моделей.
2. Перезапустите SyncVoice. Новые звонки анализируются сами после
   расшифровки; уже распознанные — `manage.py analyze_calls`
   (`--now` — сразу, с выводом результата и токенов; `--day ГГГГ-ММ-ДД`;
   `--compare` — ещё и сверка анкеты из CRM; `--force` — заново, даже если ответ уже есть).
3. Список радиостанций для сверки названий — в «Настройках».
4. «Запасные модели» в «Настройках» (через запятую, например
   `gemini-3.5-flash-lite`): когда у модели кончается дневной лимит
   бесплатного тарифа, SyncVoice сам переходит на следующую до сброса
   лимита (полночь по Калифорнии — 10–11 утра по Минску). Какие модели
   исчерпаны — видно на главной и в настройках.

Разбор промптов: `manage.py prompt_review --day ГГГГ-ММ-ДД` собирает в
`media\prompt_review\` файл с проверенными звонками: расшифровка, анкета
оператора, ответы ИИ и форма контролёра рядом. `--rerun` — заново
спросить Gemini с текущими промптами (тратит токены; `--model ИМЯ` —
другой моделью, для сравнения), `--all` — и
непроверенные звонки, `--ids 12,15` — конкретные звонки, `--limit N`.
В файле разговоры с именами — не публикуйте его.

Выгрузка уже сохранённых ответов ИИ за день (без новых запросов к Gemini), для
сравнения с отчётом контролёра: `manage.py export_ai --day ГГГГ-ММ-ДД` → файл
JSON в `media\export\`. Вместо телефонов — короткий хэш.

Отчёт контролёра + ИИ: на главной кнопка **«Отчёт контролёра + ИИ…»** —
выберите отчёт, заполненный вручную, и скачается тот же файл со столбцами ИИ
справа (зелёным — совпало с контролёром, красным — нет) и листом «Итог ИИ».
То же из консоли: `manage.py report_with_ai "Отчет записи 29.09.2026.xlsx"` →
`media\export\`. Берутся уже сохранённые ответы ИИ, Gemini не вызывается.

## Работа

- **Звонки → Загрузить из АТС** за нужный день: записи скачиваются и
  распознаются в фоне, прогресс виден на главной.
- Откройте звонок: слева плеер и субтитры, справа форма контроля.
  Всё сохраняется автоматически; **Ctrl+Enter** — отметить проверенным и
  перейти к следующему непроверенному звонку дня.
- **Скачать отчёт .xlsx** — отчёт за выбранный день в формате контролёров.

## Разработка (macOS / Linux)

```
python3 -m venv venv
venv/bin/pip install -r requirements.txt
venv/bin/python manage.py migrate
venv/bin/python manage.py run_app      # сайт + обработчик на http://127.0.0.1:8765
venv/bin/python manage.py test player
```

`runserver` сам не распознаёт — параллельно нужен `manage.py run_worker`.
Переменные окружения: `WHISPER_MODEL` (по умолчанию `small`),
`WHISPER_LANGUAGE` (`ru`; `auto` — определять язык).
